# Money Plan — themed PWA

This is the updated source package for your existing GitHub Pages app.

## Included
- Christmas red-and-cream branding and app icons
- Christmas, Summer, Winter Snow, Japan (Mount Fuji/cherry blossom palette), and Arsenal-inspired themes
- Light and dark display modes
- Existing money tracker functionality and local-device storage
- Updated service-worker cache version

## Update your existing GitHub repository
1. Extract this ZIP on your computer.
2. Open your existing `money-plan` GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload every file in this folder, including `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, and `icon-512.png`.
5. Commit changes.
6. Wait for GitHub Pages to publish, then open your existing site URL:
   https://millerarr.github.io/money-plan/
7. In Chrome on Android, reload the site. If the old app shell remains cached, close the installed app and reopen the website; the service worker cache version has been bumped.

## Important
- This ZIP is the updated website source, not a separately hosted website. Your existing GitHub Pages URL stays the same after you upload these files.
- Money data remains stored locally in the browser on each device. Themes are saved locally too.
- No Monzo integration or cloud sync is activated.
